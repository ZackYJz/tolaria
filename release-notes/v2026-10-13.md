## New Features

- 🧮 **Pascal syntax highlighting** — Pascal code blocks now get proper syntax highlighting.
- 📄 **Sharper PDF previews** — PDF attachments render with PDF.js for more reliable previews.

## Improvements

- 💾 **Markdown source preserved on save** — Switching between the rich and raw editors, or updating properties, no longer rewrites your original Markdown formatting.
- ⌨️ **Caret stays in the title after Cmd+N** — New notes keep focus in the title instead of jumping away.
- 📋 **Better Markdown pasting** — Pasting prefers the structured Markdown source when the clipboard offers one.
- 🌙 **Dark mode polish** — Standalone HTML previews stay readable in dark mode, and scrollbars are more discreet.
- 🧾 **Type array properties keep their shape** — Array-valued Type properties no longer collapse to a single value.
- ➗ **Display math no longer overlaps** — Equation tags in display math lay out cleanly.
- 🤖 **AI composer line breaks** — A trailing line break in the AI composer shows up immediately.
- 🧩 **Official Pi agent logo** — The Pi agent now uses its official logo.
- 🪟 **Cross-platform settings shortcut** — The footer shows the right settings shortcut on Windows and Linux.

## Stability and Fixes

- Fixed a race where deferred editor tab swaps could fire after the editor unmounted.
- Spreadsheet HTML cell references wait for the sheet engine, and pending HTML previews stay inert.
- Guarded invalid sheet cell selections, unmounted link toolbar lookups and stale ProseMirror selections.
- Whiteboards recover from incompatible pastes and no longer measure text before the canvas renders.
- Linked nested list children are promoted safely, and the editor bypasses a looping state during recovery.
- Linux AppImages use the host system libraries for better compatibility.
